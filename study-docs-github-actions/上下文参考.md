**上下文参考（Context Reference）**，简单来说就是**在 GitHub Actions 工作流（Workflow）中，通过一种固定的语法去“读取/引用” GitHub 系统为你准备好的内置数据**。

这些数据包含了关于当前触发事件、运行环境、密钥、变量、上一步骤结果等各种信息。

---

### 简单例子

假设你想在 GitHub Actions 中打印出**是谁触发了这次代码提交**，以及**当前的提交分支名称**：

```yaml
name: Print Context Example

on: [push]

jobs:
  show-info:
    runs-on: ubuntu-latest
    steps:
      - name: Display Github Context Info
        # 这里使用了上下文参考 syntax: ${{ github.actor }} 和 ${{ github.ref }}
        run: |
          echo "触发这次运行的人是: ${{ github.actor }}"
          echo "当前分支是: ${{ github.ref }}"

```

### 为什么需要它？

1. **获取动态信息**：每次代码提交的作者（`github.actor`）、分支（`github.ref`）、密钥（`secrets.MY_TOKEN`）都是动态变化的，通过上下文参考可以随时读取。
2. **逻辑判断（条件控制）**：你可以直接在工作流调度阶段（还没送到服务器运行前）做判断，比如：
```yaml
# 只有在 main 分支提交时才执行这个作业
if: ${{ github.ref == 'refs/heads/main' }}

```

### 打印所有上下文（调试用）

通过 `toJson()` 函数可以将整个上下文对象序列化打印，方便调试时查看所有可用字段：

```yaml
name: Print All Contexts

on:
  workflow_dispatch: # 支持在 GitHub 页面手动点击运行测试

jobs:
  print-context-job:
    runs-on: ubuntu-latest

    # 可以在 job 级别定义一些临时变量用于测试 env 上下文
    env:
      JOB_ENV_VAR: "Hello from Job Env"

    steps:
      - name: Print Github Context
        run: echo '${{ toJson(github) }}'

      - name: Print Env Context
        run: echo '${{ toJson(env) }}'

      - name: Print Vars Context
        run: echo '${{ toJson(vars) }}'

      - name: Print Job Context
        run: echo '${{ toJson(job) }}'

      - name: Print Runner Context
        run: echo '${{ toJson(runner) }}'

      - name: Print Strategy Context
        run: echo '${{ toJson(strategy) }}'

      - name: Print Matrix Context
        run: echo '${{ toJson(matrix) }}'

      - name: Print Inputs Context
        run: echo '${{ toJson(inputs) }}'
```

各上下文简介：

| 上下文 | 包含内容 |
|---|---|
| `github` | 触发事件信息：actor、ref、sha、event_name、repository 等 |
| `env` | 当前 job/step 可见的环境变量 |
| `vars` | 仓库 / 组织级别的 Variables（非 secret） |
| `job` | 当前 job 的状态和容器信息 |
| `runner` | runner 的 OS、架构、临时目录等 |
| `strategy` | matrix 策略配置（fail-fast、max-parallel） |
| `matrix` | 当前 matrix 组合的具体值 |
| `inputs` | `workflow_dispatch` 或 `workflow_call` 的输入参数 |
| `secrets` | 机密值（不可用 `toJson` 打印，防止泄露） |
| `steps` | 已完成步骤的 outputs 和 outcome |
| `needs` | 依赖 job 的 outputs 和 result |
